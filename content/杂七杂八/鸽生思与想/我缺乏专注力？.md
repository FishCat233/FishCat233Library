我觉得我最重要和最欠缺的是专注力，但欠缺专注力又同时是我的天性。

我最近几年就发现了这个问题，但我难以去保持专注思考甚至完全没有头绪。直到我最近开始模仿 tsoding 做一些小项目，静下心读一读文档才慢慢意识到如何去尝试克服。

tsoding 通常直播设置的目标都能控制在一个小时到三个小时完成，而就算大项目也能控制在每一期都在一到三小时内，并且直播期间经常会经常控制研究内容不偏离直播主题。

我在模仿他尝试进行一些项目来寻找最初的编程乐趣的时候，我发现每当看到细枝末节或者冲浪看到感兴趣的信息时，我就会产生极其强烈的冲动直接点进去然后现场学习研究——而结合以前的回忆和事后观察，我会放下手中的西瓜，然后换另一个水果，然后是另一个……

虽然过程中我是快乐的，但生活的一事无成告诉我，这是不行的。

这个问题在写文章尤其是随笔以外的文章上尤其严重。在我写文章之前，我也不知道我具体会写出什么——通常我只有一个标题，然后围绕灵感和标题边写边思考，我觉得我写文章的过程如同大模型，我只是在想办法让文章变得「像一篇文章」而不是进行什么「有预谋的表达」。我只要随便写点什么，然后找口糊的证明写上去，就写成一篇文章了。

从文章的角度回过头来看可以发现我的思考实际上经常是发散的。笔记和随笔是我最早使用和喜欢使用的文章形式，而我的笔记和随笔通常都是为了我的贪婪而生，意图想要把我每一刻所思所想都记下来。大量笔记和随笔的存在能证明我的思考是相当发散并且兴趣也是过于宽泛的。

这种发散的思想会在我思考的时刻产生新的灵感，而新的灵感就会给我的专注带来干扰。比如说我只是查一个文档就可以产生这样的链条：

1. 因为不会做，所以打开浏览器查询 API 文档
2. 感觉 API 好麻烦，思考有没有更简单的方式
3. 想到了一种方式，不知道能不能实现，所以新建标签页进行搜索
4. 发现有人做过了而且写成库了，打开库页面
5. 浏览起新库的文档……
6. 刚才搜索发现有另一个库也实现了，搜索看看

这个问题在以前就很严重，而在信息爆炸的 AI 时代，问题变得更严重了。AI 经常让我不断进行抽象思考，或者成为我好奇心跳跃到另一些点的跳板。

灵感带来了跳板，而我的各种潜意识都对逃离当前事情很感兴趣。常见的理由有不少：比如对灵感珍稀和遗忘的恐惧会让我想要赶紧写下来长篇大论生怕写错；又或者当前任务太难太复杂太麻烦，为了逃避便抓住任何机会换一个任务。

不断产生的灵感和兴趣点给我带来了相当多的困扰，我知道事物有两面性，因为今天我还能会点什么而不是什么都不会正是因为有这种感兴趣就上的冲动，虽然大部分是无用功，但还是让我不至于变得无聊。

按照文章的结构，这里应该写上做法和解法，但说实在我真没有什么感觉特别好的方法。如果好方法真有这么容易想到，那我早就被生活的冲击改变了，而不是早早就开始受这样的苦难直到 2026 年。

但也不是一点办法也没有，正如我上面提到 tsoding 所说，我在尝试模仿的过程中意识到如何去克服，指的正是我歪打正着地找到了一些改变的思路——建立一个清晰的合适的目标或者任务，然后保持警惕，预防一切偏题行为。

但是这个办法也不是完美的，因为如果任务太难，我就要查阅不少资料进行不少思考，而这会导致我思考进死胡同，然后在那里空耗时间——我认为那是另一种发散思考的体现，和之前的区别在于这种思考更加糟糕，因为专注在问题上，对于问题内还是问题外什么也没做。假装思考也是一个难以解决的问题。

就写这么多吧，我感到有些疲倦了。 *起初我认为睡眠是克服发散问题的唯一关键，但后来发现确实是关键，但不是唯一的那个，也不是最重要的那个。因为即便睡够我也会东搞西搞。*
